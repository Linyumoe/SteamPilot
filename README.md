# SteamPilot（蒸汽领航）

一个 Windows 桌面小工具，用来让 Steam 商店 / 社区等网页在国内更稳定地打开。核心思路是**把网页流量引到实测优选出来的线路**上，绕过 SNI 阻断；只加速你勾选的网站，其他网站照常直连。

> 仅加速网页浏览（商店、社区、静态资源、创意工坊预览），不加速游戏本体，不提升物理带宽。

## 首次使用（四步）

1. **安装安全证书** — 点击安装本地根证书。它只给当前 Windows 账户使用，随时可一键卸载。浏览器需要信任它，才能接受本地加速通道签发的证书。
2. **跑一遍线路优选** — 程序对候选 IP 做延迟 → 证书 → 下载测速三级漏斗筛选，挑出最快可用的线路。不改你的 DNS。
3. **勾选要加速的网站** — Steam / Epic / GitHub 等，按需要选择。
4. **启动加速** — 程序把勾选的网站通过本地 PAC 导向加速通道，其余网站完全直连。

停止加速或退出程序时，系统代理会自动恢复到原来的设置。

## 工作原理

浏览器访问被勾选的网站时，实际走的是两段连接：

```
浏览器 ──TLS──> 本地代理 ──TLS──> CDN 边缘节点
 SNI=真实域名        SNI=合法 CDN 别名（绕过阻断）
 证书=本地 CA 签发     证书=CDN 签发（严格验签）
                     HTTP Host=真实域名（决定路由）
```

- **为什么装证书**：本地代理要终止 TLS 才能把「对浏览器用真域名、对 CDN 用别名」分开，所以浏览器必须信任本地 CA。
- **别名 SNI + 真 Host**：SNI 只用来过握手和验签，真正决定访问哪个站点的是 HTTP Host 头。这是绕过 SNI 阻断、又不关闭证书校验的关键。
- **线路优选**：多条线路按真实请求耗时（EWMA）动态评分，节点失败自动切换到下一个候选。
- **流量接管**：用系统代理 + 本地 PAC 文件，只对勾选域名返回代理地址；不需要管理员权限、不装虚拟网卡、不装驱动。

## 隐私与安全

- **只有勾选的网站经过本工具**，且这些网站的 HTTPS 内容会在本机代理处解密转发 —— 请勿在不信任的机器上启用。
- 不记录 Cookie / Token / 请求体，日志只含域名、IP、SNI 和耗时。
- 证书需你显式点击安装，绝不静默安装；提供一键卸载。
- 对上游 CDN 始终**严格验证证书**，从不跳过验证。
- 非白名单域名字节透传，不做中间人。

## 构建

需要 Windows + Rust 工具链。Tauri 2 项目，前端为原生 HTML/CSS/JS，无 Node 构建步骤。

```bash
cargo build --release
# 产物：target/release/steampilot.exe
```

运行测试：

```bash
cargo test --release
```

## 更新

设置页「检查更新」会读取 [GitHub Releases](https://github.com/Linyumoe/SteamPilot/releases/latest) 的最新版本并提示；有新版本时用系统浏览器打开发布页手动下载，程序不会自动下载或替换自身文件。启动时默认静默检查一次，可在设置里关闭。

发布新版本：打个 `v` 开头的 tag 并推送，GitHub Actions 会自动构建并创建 Release：

```bash
git tag v0.2.0 && git push origin v0.2.0
```
